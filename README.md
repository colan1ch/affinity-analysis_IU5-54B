# Аффинтивный анализ чеков покупок

Учебный проект по анализу данных о покупках. Данные собраны на основе реальных чеков из магазина.

### Описание данных
Файл `cheki.csv` содержит записи о товарах из чеков:
- `Фамилия_Номер_покупки` — идентификатор покупателя и номера чека
- `Продукт` — название товара
- `Стоимость` — цена товара
- `Тип` — категория товара (Алкоголь, Еда, Фастфуд, Сигареты, Напитки и др.)
- `Время покупки` — время совершения покупки

Данные включают несколько тысяч строк, представляющих покупки разных людей.

### Содержание проекта
В Jupyter Notebook `affitiny_analysis.ipynb` выполнена следующая работа:
- Загрузка и предварительная обработка данных с использованием pandas
- Описательный анализ (распределение по категориям, времени покупок, стоимости)
- Аффинтивный анализ для выявления товаров и категорий, часто покупаемых вместе
- Визуализация результатов (matplotlib, seaborn)
- Построение дерева решений и графа ассоциаций с помощью networkx
